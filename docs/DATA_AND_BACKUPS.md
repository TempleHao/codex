# 数据、备份与跨设备移交

GitHub Pages 版的记录保存在当前浏览器。手机与电脑各自保存，清除网站数据前请先导出备份。


页面「导出备份」生成 `life-workbench-backup` **v2**，包含人生看板的生活线索、经历感受与发现、回顾，以及待办、状态、计划日、截止日、原文、阅读书架、划线与本人想法、阅读统计、影音作品与观看历史、感想、网页新增的独立思考及关联编号。用「恢复备份」选取导出的 JSON，可恢复到当前浏览器或本地服务端，增量补回缺少的记录。仍支持只含待办与原文的 **v1** 备份；恢复 v1 会保留已有看板、阅读与思考。

人生看板保存于 `life.board`。旧数据或旧 v2 备份没有该字段时，新应用按空看板读取；更新阅读、思考或恢复旧备份时，已有看板记录会保留。原有待办继续保存与读取，不会自动改成人生线索。影音保存于 `life.media`；旧资料缺少该字段时按空片单读取，恢复旧备份保留已有影音资料。公开博客归档单独缓存在 IndexedDB，不进入生活备份；博客原文可以从公开同步源重新取得。

相同编号的内容或已有阅读统计若冲突，整次恢复失败，现有数据不变；备份恢复不会覆盖或删除当前记录。阅读页「导入阅读 JSON」采用另一种合并规则：新资料更新相同编号，保留其他书籍与笔记。「导出阅读」只移交阅读资料，跨设备完整迁移请用页脚的「导出备份」。

恢复支持 20 MB 以内、最多 5000 条任务的备份，浏览器总存储量还受本机可用空间限制。备份包含私密经历、原文、笔记与思考，请保存到自己控制的位置，不要提交到公开仓库。Pages 版保留原有浏览器存储键，旧待办会继续读取；设备与浏览器之间不会自动同步。

本地 SQLite 开发版可使用页面导出获得一致性快照；不要在 SQLite 服务运行时只复制主数据库文件而遗漏 WAL。若需拷贝目录，先停止本应用，再完整复制数据目录。

删除待办时，同一批的其他待办仍会保留共同原文；删除该批最后一条待办时，原文也会一起删除。已下载的备份不受删除操作影响。

默认没有自动定时备份，请定期手动导出。
