# 本机口令与加密

GitHub Pages 版首次打开需设置至少 8 个字符的本机口令。默认勾选「记住这台设备 30 天」，验证后在这个浏览器刷新、重新打开或开新标签页可直接进入；到期再输入口令。解锁后才挂载工作台和自动更新组件，阅读、影音和博客自动更新沿用已有流程。

## 保护的内容

人生看板、阅读库、影音、网页新增思考、财务账单、事务与聊天原文，作为一份工作台文档在当前浏览器中加密。首次设置保留原有内容并在同一个本地存储键中替换为密文；写入失败时保留原记录，不能把错误当作空数据覆盖。

密钥由口令通过 PBKDF2-SHA256 派生，工作台使用 AES-256-GCM 加密，每次写入生成新的随机 IV。未记住设备时，不可导出的解锁密钥只保留在页面内存；选择记住后，密钥与固定期限保存在独立 IndexedDB 中。应用不保存口令，也不向 GitHub 上传口令、密钥或工作台记录。错误口令或被修改的密文不能解锁，失败不会重写数据。

普通关闭或离开页面清除内存中的解锁密钥，保留你选择的设备记忆。主动点顶部锁定会撤销这台设备的记忆，其他已打开标签页也会收起私人内容；请先保存草稿。恢复备份、导入与编辑仍遵循现有原子保存和冲突检查；锁定状态不允许读取或写入工作台。清空工作台会保留本机口令，并加密保存空记录；「忘记口令」中的重置会在再次确认后删除工作台密文。

## 记住设备的边界

30 天是从这次口令验证开始的固定期限，日常打开不会延长期限。恢复前验证期限、当前密文与保存的密钥是否匹配，并核对撤销标记；过期、密钥错误、密文被修改或存储不可读时要求口令，不会清空记录。存储失败时仍允许使用本次已验证会话，并提示下次需要口令。

共享设备请取消勾选，选择会在下次打开保留，刷新或重新打开需验证。忘记口令并重置工作台也会撤销设备记忆；设备记忆不属于完整 JSON 备份，换手机或浏览器要重新验证。

记住设备意味着有效期内任何能操作这个浏览器的人都可以打开人生空间。这适合由锁屏保护的个人手机或电脑，不能替代设备锁；不可导出密钥仍可被同源应用调用解密，不等于硬件保险箱或银行认证。期限由本机应用执行，不是服务器账户的有效期。

## 多标签页保存

保存操作在同一浏览器的页面之间串行执行，并核对密文的已提交版本。版本标记只包含 SHA-256 指纹，保存在 IndexedDB 中，不复制工作台内容、口令或密钥。读取到旧版本时先等待同步；无法确认一致时取消这次保存、保留草稿，避免覆盖另一页的记录。保存需要支持 Web Locks 与 IndexedDB 的现代浏览器；缺少 Web Locks 时仍可解锁和导出已有记录，写入会提示升级浏览器。

浏览与完整备份属于只读操作。若同步或存储错误持续存在，请先复制未保存文字并导出完整备份，再检查浏览器是否允许本站使用本机存储；不要直接清除浏览器数据。页面异常关闭造成的未确认版本不会自动覆盖现有记录，必要时可在另一浏览器空间恢复备份。

## 保护范围

这是一套本机解锁机制，不是服务器账号。手机和电脑各有自己的浏览器资料与口令，不会自动共享同一份工作台；可以用完整备份移交记录。

公开博客原文、网页源代码与静态资源仍公开。微信读书的云端快照继续使用原有独立加密方案；本机保存的自动解锁 CryptoKey、Trakt 连接、授权等待信息及图片缓存沿用各自的存储方式，不属于这份工作台密文。它不替代设备锁、浏览器和系统账户的保护。

完整 JSON 备份是明文，下载前需先解锁，下载后由你保管。不要将账单、备份、口令或 API Key 提交到公开 GitHub。SQLite 本地开发版继续使用本机服务端存储，这份 Pages 浏览器解锁机制不为开发服务器提供远程账号认证。

## 忘记口令

应用不能找回口令或替你解密。可在解锁页点「忘记口令」，阅读删除说明并确认重置；设置新口令后，用以前导出的备份恢复。没有口令也没有备份时，原工作台密文不能恢复。公开博客可重新获取；外部阅读和影音资料能否补回，取决于原连接与接口返回范围。
