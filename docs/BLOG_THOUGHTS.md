# 博客与思考

公开博客的「说说」合并进入「思考」，收录 1646 条记录，日期范围为 2020-03-24 至 2026-10-08。它与网页中新建的思考共处一个时间线，可按全部、随手写或博客来源筛选，也可按年份查看、搜索，并以每页 40 条浏览。

归档保留原始日期、来源编号与原文，原文只读；原来源链接用于回到博客。可以为旧文字另存此刻感受，感受作为独立思考保存，并保留对应来源，不覆盖原文。首页「偶然重逢」也可以从思考来源中随机带回旧记录。

博客数据从公开 RSS 历史同步到同站点 `blog-sync.json`。数据工作流通常每 3 小时增量更新，每月全量核对。网页每次打开时用 `no-store` 获取最新文件；请求失败则使用本机 IndexedDB 缓存。缓存与新增思考分开保存。

博客归档不放进完整生活备份，清除浏览器数据后可重新从公开同步文件读取；用户自行新写的思考仍会纳入原有完整备份。源码仓库不保存个人博客原文。更多更新机制见 [自动更新资料](AUTOMATIC_UPDATES.md)，备份范围见 [数据与备份](DATA_AND_BACKUPS.md)。
