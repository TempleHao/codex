# 人生看板的产品方向

人生应用的核心是帮助使用者梳理生活的线索，直观看到自己的经历、牵挂、兴趣和变化，支持回顾、自省、自我发现与成长。首页是人生看板。

## 内容各有位置

- **生活线索**：持续关注的兴趣、牵挂、疑问和方向。可以记录当下的理解，也可以暂放或归档，没有必须完成的要求。
- **经历、感受与发现**：发生了什么，自己如何感受，从中发现了什么。保留原话和日期，可以关联一条线索，也可以独立记录。
- **回顾**：在某个时点回看记录，写下自己注意到的事、发生的变化和愿意保留的东西。
- **阅读与思考**：保存阅读足迹、书籍、划线与自己的思考。阅读本身、享受一本书、留下一个未解的疑问，都有独立的价值。
- **事务**：需要处理的日常安排与琐事，作为一个辅助工具保存。

衣着、饮食、居住、出行、影音、阅读、思考、工作、健康、关系和财务等领域帮助整理内容；领域中的空白不代表缺陷。看板的记录数量只是内容规模，不是生活表现或成长程度的评分。

## 设计与迭代原则

不要求使用者把阅读、感受或思考转换成待办，不以任务完成率衡量人生。没有明确目的的兴趣、暂时无法解决的牵挂和单纯值得回味的经历，都应能自然留在看板上。

展示真实记录及来源，让使用者自己辨认其中的联系。初始页面保持为空，提示语和表单占位内容不自动保存为经历，不根据稀少记录制造人格判断、心理标签或成长分数。

后续可以加入更丰富的年度回顾、跨领域关联、兴趣变化与阅读偏好展示。任何自动发现都应能回到原记录核对，让使用者解释和修正；不自动生成并保存对使用者的结论。

当前继续采用免费的 GitHub Pages；资料保存在设备的浏览器，通过完整备份交换。旧待办、阅读与思考数据保留，新增看板内容和它们一起备份。
