# 偶然重逢：阅读回顾

有些句子当时让人停下来，却很少有机会再读。「偶然重逢」把已经留下的阅读痕迹轻轻带回眼前，帮助重新理解一本书和当时的自己。

## 在哪里看

保存阅读笔记后，人生看板和阅读页各有一张卡片，它们共用本次打开抽取的内容。切换页面不会重新抽取，刷新或重新打开应用时会重新随机选择。初次加载个人资料后才抽取，页面不放虚构示例。

- **都看看**：从有划线原文或本人想法的笔记中抽取；同时有两者时先显示自己的想法，原摘录可展开回看。
- **划线**：只抽取含非空原文的笔记。
- **我的想法**：只抽取含非空本人想法的笔记，包括没有原摘录的点评。

来源包括已经确认保存的微信读书资料和手动导入的阅读 JSON。独立思考和影音感想暂不进入这个抽取池。

## 怎么回顾

每次只展示一条，标明关联书籍及资料中已有的作者、章节和日期。长内容先展示前 280 个字符，可以「展开全文」。原文和自己的想法分别标注，缺少的日期或章节不补造。

「换一条」按当前筛选随机选择尚未看过的条目；每轮看完后开始新一轮，有多条时避免紧邻重复。一条笔记即使同时含划线和想法也只计一个条目。这个轮次仅存在于本次页面运行中，刷新后重新开始，不记录跨设备或永久阅读进度。

「查看这条笔记」会进入阅读页、选中对应书籍和划线/本人想法标签，并滚动、聚焦该条笔记。如果之前的书架搜索或筛选妨碍定位，会先清除它们。需要继续写点什么时，可使用详情里原有的「写一段思考」。

## 没有内容时

首页没有可回看的笔记时不显示卡片，阅读页显示导入提示。只有书架或笔记总数、没有实际文字时，无法抽取内容。

微信读书用户可在 **Actions → Publish GitHub Pages → Run workflow** 勾选笔记同步，等待同步和部署成功，再到网页解锁、预览并「保存到阅读」。这些步骤完成后才会进入本机抽取池。说明见 [微信读书同步](GITHUB_READING_SYNC.md)。也可以通过阅读 JSON 导入。

某个筛选下没有内容时可以切回另一个筛选。确认导入新笔记后，卡片会随资料更新；被移除的笔记不会继续显示。

## 数据与使用范围

浏览、换一条、筛选、展开和定位都不会改写笔记、建立待办或保存新的记录，也不写入已读状态。抽取不调用外部 AI、微信读书或第三方接口，不保存额外的笔记副本、口令或令牌。原有完整备份格式、存储键及授权配置保持不变。

这里提供的是阅读回顾，不据笔记生成对使用者的心理判断或成长评分。可以只读一句，也可以暂时不看。
