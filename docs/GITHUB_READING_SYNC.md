# 用 GitHub 同步微信读书

微信读书由 GitHub Actions 在服务器上读取，GitHub Pages 提供加密后的同步文件。网页只访问自己站点的文件，在当前浏览器中解锁、预览，确认后才合并到书架。整个过程只使用 GitHub，不需要购买服务器或域名，也不需要把微信读书 API Key 填入网页。

参考站通过本站接口中转请求；GitHub Pages 无法运行这种实时后台。本项目用 Actions 定时取回资料，避免网页直接请求微信读书官方接口时的跨域限制。同步不是实时中转：微信读书中的新资料要等下一次工作流完成并发布后，网页才能读取。

## 首次配置

打开仓库 [Settings → Secrets and variables → Actions](https://github.com/TempleHao/codex/settings/secrets/actions)，通过 **New repository secret** 添加两个仓库 Secret：

| 名称 | 填写内容 |
| --- | --- |
| `WEREAD_API_KEY` | 自己的微信读书官方 API Key。 |
| `WEREAD_SYNC_PASSPHRASE` | 专门用于解锁同步资料的随机长口令。网页解锁时输入同一份口令。 |

解锁口令与微信读书 API Key 是两回事。可先在网页「微信读书同步 → 首次配置同步」点击「生成随机口令」，复制并保存到密码管理器；关闭配置会清除本次生成值。也可用密码管理器生成至少 32 位随机口令，不要复用日常登录密码。不要把 Secret 写进代码、Issue、聊天记录、公开仓库变量或工作流输入。GitHub 的 **Variables** 不等同于 **Secrets**。

Secret 保存后，打开 [Actions → Publish GitHub Pages](https://github.com/TempleHao/codex/actions/workflows/pages.yml)，选择 **Run workflow**。默认只同步书架和阅读统计；需要划线与本人想法时，勾选工作流提供的笔记读取选项。完成部署后打开[人生看板](https://templehao.github.io/codex/)，进入「阅读 → 微信读书同步」。

本开发环境对仓库 Secret 管理接口的认证权限不足，无法替使用者确认或设置这些值。代码、测试和未配置提示不能证明真实账号已经连通；是否配置成功，以该次工作流的同步状态和网页解锁预览为准。

## 在网页使用

1. 展开「微信读书同步」，填写「同步资料解锁口令」。
2. 点击「读取同步资料」。网页下载本站同步文件，在浏览器中解密并严格校验；读取开始后会清空口令输入框。
3. 查看「已读取，等你确认」中的书籍、笔记和统计。预览不会修改已有记录。
4. 点击「保存到阅读」才合并到当前浏览器；也可以「放弃预览」或「关闭同步」。

关闭、离开阅读页或刷新后不会保留解锁口令。口令不上传到微信读书，不写入浏览器存储、备份或构建文件。解锁后的阅读资料只在确认保存后进入当前浏览器的个人记录；手机和电脑仍须各自解锁、确认。

同编号书籍和笔记采用本次新值，其他条目保留。每日阅读历史按日期合并，同日采用新值；今年的同步不会删除已经导入的往年日明细。人生看板、独立思考和事务不会被阅读同步覆盖。存储空间不足时旧记录不变，预览保留，可释放空间后重试保存。

## 调度与资料范围

工作流在代码发布、手动运行及每天两次的定时任务中执行。GitHub 的定时任务可能延迟，公开仓库长时间无活动时也可能停用；需要立即更新时使用 **Run workflow**。定时读取不依赖 Codex 页面保持打开。

读取范围包括官方书架、累计阅读统计与今年的每日阅读记录。成功更新时会合并上一份云端快照，保留旧笔记和已经累计的日记录；默认不读笔记不会清除以前同步的笔记。笔记读取是可选项：笔记本目录上限为 1000 本，内容总量上限为 10000 条划线与本人想法。官方明确给出某类内容数量为 0 时跳过对应内容接口，数量未知时仍读取核实。超过任一上限或分页异常会拒绝本次结果，不发布半份资料。官方书签目前只有数量，没有可读取的内容。历史年度自动补全与实时监听尚未实现。

接口的 `upgrade_info` 会中止本次读取，需要更新官方技能接口版本后再运行。服务端采用腾讯官方 WeChatReading 技能约定；安装技能不会改变微信读书浏览器的跨域规则。

## 发布内容与加密

`weread-sync.json` 是公开 Pages 站点上的**加密阅读快照**，并非明文个人资料。它使用随机盐、PBKDF2-SHA-256（600000 次迭代）派生密钥，再用 AES-256-GCM 加密并验证完整性。每次加密使用新的随机参数；文件与解密后的资料都限制在 20 MB 以内，并经过版本、字段和关联校验。

公开站点的访客可以下载密文，文件大小和更新时间也是公开的，因此解锁口令需要足够随机、足够长。口令和 API Key 保存在 GitHub Secrets；Actions 运行期间会读取这些 Secret 和微信读书资料，发布目录不包含 Secret 或明文阅读资料。不把同步快照提交进源代码，也不发布人生看板、独立思考、事务或完整备份。

`weread-sync-status.json` 只包含同步状态、时间与固定错误码，不包含密钥、口令、书名、笔记或官方错误原文。网页通过状态区分未配置、已就绪和同步失败。更新失败时可能保留上一份已发布的加密快照；网页会提示本次未更新，不能把旧文件的解锁成功理解为最近一次官方读取成功。

请稳定保管解锁口令。更新时需要用它解锁上一份云端快照后合并历史；更换口令会使旧快照无法读取，默认停止更新并保留旧密文。确实要更换时，先在网页用旧口令解锁并保存、导出备份，再更新 Secret，并在手动工作流中明确选择 `reset_history` 重建云端资料。只有新的官方读取成功才会覆盖旧快照；该选项不会清空浏览器，但本次未从接口取回的旧云端历史可能不再出现在新快照中。旧口令不能解锁新的快照，已经下载的旧密文不会随新部署自动消失。

停止后续读取可删除 API Key Secret；需要撤销微信读书授权时在官方渠道处理。更新失败会保留上一份加密快照，删除 Secret 不等于移除已发布的文件。

## 常见情况

| 页面或工作流现象 | 处理方式 |
| --- | --- |
| 提示还没有配置或没有同步资料 | 检查两个仓库 Secret 的名称，运行工作流并等待部署完成。 |
| 解锁没有完成 | 核对专用解锁口令；确认更换口令后已完成一次新部署。损坏或格式不支持的文件也会拒绝解锁，已有记录不变。 |
| 本次同步失败，仍可读取旧资料 | 查看 Actions 中固定错误提示，修正配置后重试；预览中的同步时间表示该份资料的实际时间。 |
| 笔记本目录超过 1000 本（`notebook_limit_exceeded`） | 不勾选笔记选项，先同步书架和统计；需要笔记时可按阅读 JSON 格式分批整理后导入。 |
| 划线与想法超过 10000 条（`note_limit_exceeded`） | 本次完整读取停止，不会发布截断资料；可关闭笔记读取或按阅读 JSON 格式分批导入。 |
| 保存没有完成 | 保留预览并先导出本机备份；释放浏览器空间后重试。 |

测试使用虚构的微信读书响应与真实加密、解密过程，验证预览确认、错误口令、资料合并、空间不足和手机布局。它们不代替个人 API Key 的真实工作流验证。阅读数据格式、统计口径和完整备份规则见 [微信读书与阅读资料](WECHAT_READING.md)。
