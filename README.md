# 有序 · 人生工作台

面向 iPhone 和电脑的中文个人生活工作台。首页是人生看板：留下正在关注的生活线索、经历中的感受与发现，再回看自己的变化。阅读、影音与思考各有独立的记录空间，待办用于辅助处理具体事务。产品原则见 [人生看板的产品方向](docs/PRODUCT_DIRECTION.md)。事务的聊天收集仍采用「整理一大段事情 → 复制结果 → 预览编辑 → 批量保存」，网页不调用外部 AI 服务，也不会自动读取聊天。

当前发布目标为**只使用 GitHub 的免费静态版**：通过 GitHub Pages 展示网页，个人工作台记录保存在使用者的浏览器里，用导出与恢复在设备间交换。可选的微信读书同步由 GitHub Actions 读取资料，只发布加密后的阅读快照，浏览器解锁预览后再决定保存。完整说明见 [GitHub Pages 发布指南](docs/GITHUB_PAGES.md)和[免费微信读书同步配置](docs/GITHUB_READING_SYNC.md)。源代码中的 SQLite 服务端版本仍可本地开发，Pages 版本不使用这些接口。

## GitHub Pages 静态版

```sh
npm ci --ignore-scripts
LIFE_BASE_PATH=/codex npm run build:preview
npm run serve:preview
```

`preview-out/` 是可发布的静态目录。构建过程在临时目录运行，不改写原应用、锁文件或个人数据库，不包含服务端 API、密钥或明文个人记录。部署工作流可另行加入加密阅读快照与不含个人资料的同步状态文件。工作流只部署静态输出，不需要购买域名或服务器。GitHub Free 的公开仓库可使用 Pages；不会自动改变仓库可见性。

静态版支持人生看板、待办、原文、阅读、影音与思考的完整导出与恢复。手机与电脑各自保存；清除网站数据会丢失本机内容，请先导出备份。完整工作台的跨设备云同步、账号、后台提醒尚未实现。人生看板、思考、事务与完整备份不上传到 GitHub；可选的微信读书同步只发布加密阅读快照，微信读书入口只请求本站文件；可选 Trakt 入口在用户跳转授权后直接请求 Trakt 官方授权与资料接口。

可用 `npm run test:preview` 验证构建后的静态版。该测试只读静态产物，并使用独立浏览器上下文中的假数据。

事务模块支持今天 / 收件箱 / 全部待办 / 已完成视图、手动新建、JSON 与逐行清单导入、逐条编辑与排除、计划日与截止日分开、原文溯源、完成与撤销、搜索。Pages 版使用浏览器本地存储；本地服务端开发版使用 SQLite。

## 人生看板、阅读、影音与思考

「人生看板」是默认首页。生活线索可以是兴趣、牵挂、疑问或方向，记录它为何值得继续关注；经历记录可以留下某天的经历、感受或发现，并按需关联一条线索。回顾围绕三问展开：最近注意到了什么、什么正在变化、有什么想继续保留。它们按真实记录保存，允许暂放、回看和重新理解。

「阅读」支持电子书、有声书和文章条目，按书名、作者、类型与阅读状态筛选；导入每日阅读秒数后显示年度热力图，缺少数据的日期保留空白。书籍、划线与本人想法留下阅读痕迹，阅读时长和常读时段帮助理解自己的兴趣与习惯。触动你的句子可以直接带入一段思考，也可以只留在书架里回看。

「影音」按「回顾、片单、感想」整理故事与自己的生活。电影和整部剧各占一张卡，单集与重看记录收进分季详情；年度足迹按观看日统计，题材每部作品只计一次。可以手动记录、导入 JSON，或从 Trakt 跳转授权读取后确认导入；保存连接后，每次打开网页自动更新，并自动续期授权，连接信息仅保存在本机且不进入备份。人生看板只在主动点击「留在人生看板」后新增感受。海报自动补查作品详情、迁移旧图源，并支持匿名诊断。配置与统计口径见 [Trakt 影音接入](docs/TRAKT.md)。

「思考」支持自由记录、新建、编辑、搜索与删除，保留感受、疑问和观点的变化。关联书籍与原摘录是可选信息。阅读中的「安排阅读」「把摘录变成行动」和思考中的「转为待办」收在默认折叠的「事务工具」里；需要处理具体事务时才打开草稿，确认后保存。

阅读资料可以通过 JSON 预览后导入。另有「微信读书同步」入口：在仓库 Secrets 配置自己的官方 API Key 和专用解锁口令，GitHub Actions 读取书架、累计统计、今年每日记录及可选划线想法，加密后随 Pages 发布。网页输入解锁口令，读取本站快照并预览，点击「保存到阅读」才合并。API Key 不进入浏览器；解锁口令只用于本次操作，不写入浏览器存储、备份或构建产物。

此前以 Pages 来源发送官方接口跨域预检得到 HTTP 401，允许来源为 `https://weread.qq.com`，网页直连不能作为同步入口。当前改由 Actions 读取，避免这一浏览器限制。仍需在仓库配置两个 Secret、完成真实工作流，才能确认个人账号读取成功；本地测试只使用虚构资料。配置步骤及加密发布边界见 [GitHub 微信读书同步](docs/GITHUB_READING_SYNC.md)，数据格式、统计口径、官方技能安装及当前边界见 [微信读书与阅读资料说明](docs/WECHAT_READING.md)。

## 本地运行

需要 Node.js 24 或更新版本。所有命令在仓库根目录执行：

```sh
cd /workspace/codex
npm ci --ignore-scripts
npm run dev
```

服务默认仅绑定 `127.0.0.1:3000`。正式构建可使用 `npm run build`，然后 `npm start`。

这里运行的是 SQLite 服务端开发版，尚无登录、推送通知或多用户隔离。不要将这个服务直接暴露到公网。要使用 GitHub Pages，请使用上面的静态构建；添加到主屏幕的清单和图标已准备，尚无应用页面离线缓存和后台通知能力；影音海报有独立图片缓存。

不加载海外字体或第三方统计脚本。任务和原文保存到当前服务器的 `.data/life.sqlite`，不会随着页面关闭消失。`LIFE_DATA_DIR` 可指定数据目录，避免在重新部署时遗失数据。

## 从聊天导入

直接把杂事发给聊天助手，再要求按 [聊天收集约定](docs/CHAT_CAPTURE.md) 输出。复制 JSON 代码块的内容到收件箱，点「预览」，逐条调整或取消勾选，确认后保存。

最简 JSON：

```json
{
  "version": 1,
  "sourceText": "最近想洗牙，但还没选诊所。也想整理一下电脑桌。",
  "tasks": [
    {
      "title": "选择牙科诊所并咨询洗牙预约",
      "area": "健康",
      "notes": "先询问价格和可预约时间。",
      "needsClarification": ["选择哪家诊所？"],
      "sourceExcerpt": "最近想洗牙，但还没选诊所。"
    },
    { "title": "整理电脑桌", "area": "生活" }
  ]
}
```

也支持每行一条、编号清单，以及以下 Markdown：

```text
- [ ] 联系诊所 | 领域:健康 | 备注:询问洗牙预约 | 待确认:选择哪家诊所
- [ ] 整理电脑桌 | 领域:生活
```

有明确日期时可附加 `计划:2026-10-08`、`截止:2026-10-09`、`优先级:高`。日期必须是实际存在的 `YYYY-MM-DD`；「改天」「下周」「每周」等表达不由网页推算，请在预览中确定，周期任务尚不会自动重复。

JSON 每批最多 100 条；单条标题最多 300 字。粘贴自然语言时，网页只做逐行导入，不具有语义分析能力。复杂段落请先由聊天助手整理。

## 数据与备份

页面「导出备份」生成 `life-workbench-backup` **v2**，包含人生看板的生活线索、经历感受与发现、回顾，以及待办、状态、计划日、截止日、原文、阅读书架、划线与本人想法、阅读统计、影音作品与观看历史、感想、独立思考及关联编号。用「恢复备份」选取导出的 JSON，可恢复到当前浏览器或本地服务端，增量补回缺少的记录。仍支持只含待办与原文的 **v1** 备份；恢复 v1 会保留已有看板、阅读与思考。

人生看板保存于 `life.board`。旧数据或旧 v2 备份没有该字段时，新应用按空看板读取；更新阅读、思考或恢复旧备份时，已有看板记录会保留。原有待办继续保存与读取，不会自动改成人生线索。影音保存于 `life.media`；旧资料缺少该字段时按空片单读取，恢复旧备份保留已有影音资料。

相同编号的内容或已有阅读统计若冲突，整次恢复失败，现有数据不变；备份恢复不会覆盖或删除当前记录。阅读页「导入阅读 JSON」采用另一种合并规则：新资料更新相同编号，保留其他书籍与笔记。「导出阅读」只移交阅读资料，跨设备完整迁移请用页脚的「导出备份」。

恢复支持 20 MB 以内、最多 5000 条任务的备份，浏览器总存储量还受本机可用空间限制。备份包含私密经历、原文、笔记与思考，请保存到自己控制的位置，不要提交到公开仓库。Pages 版保留原有浏览器存储键，旧待办会继续读取；设备与浏览器之间不会自动同步。

本地 SQLite 开发版可使用页面导出获得一致性快照；不要在 SQLite 服务运行时只复制主数据库文件而遗漏 WAL。若需拷贝目录，先停止本应用，再完整复制数据目录。

删除待办时，同一批的其他待办仍会保留共同原文；删除该批最后一条待办时，原文也会一起删除。已下载的备份不受删除操作影响。

默认没有自动定时备份，请定期手动导出。

## 验证

```sh
npm run typecheck
npm test
npm run build
npm run test:e2e
```

端到端测试使用系统 Chromium（默认 `/usr/bin/chromium`，可用 `CHROMIUM_PATH` 改路径），启动独立服务和临时测试数据目录，不读写个人数据库。

当前时间以 `Asia/Shanghai` 解释。筛选「今天」包括计划今天、今天到期和已逾期的未完成任务；日期每分钟检查一次。
