# 有序 · 人生工作台

面向 iPhone 和电脑的中文个人待办原型。当前专注于「在聊天中整理一大段事情 → 复制结果 → 预览编辑 → 批量保存」，不调用任何外部 AI 服务，也不会自动读取本次聊天。

当前发布目标为**只使用 GitHub 的免费静态版**：通过 GitHub Pages 展示网页，数据仅存在使用者的浏览器里，用导出与恢复在设备间交换。完整说明见 [GitHub Pages 发布指南](docs/GITHUB_PAGES.md)。源代码中的 SQLite 服务端版本仍可本地开发，Pages 版本不使用这些接口。

## GitHub Pages 静态版

```sh
npm ci --ignore-scripts
LIFE_BASE_PATH=/codex npm run build:preview
npm run serve:preview
```

`preview-out/` 是可发布的静态目录。构建过程在临时目录运行，不改写原应用、锁文件或个人数据库，不包含 API、密钥或个人记录。工作流只部署静态输出，不需要购买域名或服务器。GitHub Free 的公开仓库可使用 Pages；不会自动改变仓库可见性。

静态版支持原有待办操作、批量导入、原文、导出与恢复。手机与电脑各自保存；清除网站数据会丢失本机内容，请先导出备份。跨设备云同步、账号、后台提醒尚未实现。它不把个人记录上传到 GitHub。

可用 `npm run test:preview` 验证构建后的静态版。该测试只读静态产物，并使用独立浏览器上下文中的假数据。

已实现：今天 / 全部 / 已完成视图、手动新建、JSON 与逐行清单导入、逐条编辑与排除、计划日与截止日分开、原文溯源、完成与撤销、搜索、SQLite 持久化、完整 JSON 导出与原子恢复。

## 本地运行

需要 Node.js 24 或更新版本。所有命令在仓库根目录执行：

```sh
cd /workspace/codex
npm ci --ignore-scripts
npm run dev
```

服务默认仅绑定 `127.0.0.1:3000`。正式构建可使用 `npm run build`，然后 `npm start`。

这里运行的是 SQLite 服务端开发版，尚无登录、推送通知或多用户隔离。不要将这个服务直接暴露到公网。要使用 GitHub Pages，请使用上面的静态构建；添加到主屏幕的清单和图标已准备，尚无离线缓存和后台通知能力。

不加载海外字体或第三方统计脚本。任务和原文保存到当前服务器的 `.data/life.sqlite`，不会随着页面关闭消失。`LIFE_DATA_DIR` 可指定数据目录，避免在重新部署时遗失数据。

## 从聊天导入

直接把杂事发给聊天助手，再要求按 [聊天收集约定](docs/CHAT_CAPTURE.md) 输出。复制 JSON 代码块的内容到收件箱，点「预览」，逐条调整或取消勾选，确认后保存。

最简 JSON：

```json
{
  "version": 1,
  "sourceText": "最近想洗牙，但还没选诊所。也想整理一下电脑桌。",
  "tasks": [
    {
      "title": "选择牙科诊所并咨询洗牙预约",
      "area": "健康",
      "notes": "先询问价格和可预约时间。",
      "needsClarification": ["选择哪家诊所？"],
      "sourceExcerpt": "最近想洗牙，但还没选诊所。"
    },
    { "title": "整理电脑桌", "area": "生活" }
  ]
}
```

也支持每行一条、编号清单，以及以下 Markdown：

```text
- [ ] 联系诊所 | 领域:健康 | 备注:询问洗牙预约 | 待确认:选择哪家诊所
- [ ] 整理电脑桌 | 领域:生活
```

有明确日期时可附加 `计划:2026-10-08`、`截止:2026-10-09`、`优先级:高`。日期必须是实际存在的 `YYYY-MM-DD`；「改天」「下周」「每周」等表达不由网页推算，请在预览中确定，周期任务尚不会自动重复。

JSON 每批最多 100 条；单条标题最多 300 字。粘贴自然语言时，网页只做逐行导入，不具有语义分析能力。复杂段落请先由聊天助手整理。

## 数据与备份

页面「导出备份」导出待办、状态、计划日、截止日、原文和关联编号。用「恢复备份」选取导出的 JSON，可恢复到空目录或增量补回缺少的记录。相同编号的内容若冲突，整次恢复失败，现有数据不变；恢复不会覆盖或删除当前记录。

恢复接口当前支持 5 MB 以内、最多 5000 条任务的备份。备份包含私密原文，请保存到自己控制的位置。可使用页面导出获得一致性快照；不要在 SQLite 服务运行时只复制主数据库文件而遗漏 WAL。若需拷贝目录，先停止本应用，再完整复制数据目录。

删除待办时，同一批的其他待办仍会保留共同原文；删除该批最后一条待办时，原文也会一起删除。已下载的备份不受删除操作影响。

默认没有自动定时备份；部署阶段再配置备份与恢复演练。

## 验证

```sh
npm run typecheck
npm test
npm run build
npm run test:e2e
```

端到端测试使用系统 Chromium（默认 `/usr/bin/chromium`，可用 `CHROMIUM_PATH` 改路径），启动独立服务和临时测试数据目录，不读写个人数据库。

当前时间以 `Asia/Shanghai` 解释。筛选「今天」包括计划今天、今天到期和已逾期的未完成任务；日期每分钟检查一次。
